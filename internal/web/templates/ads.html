Best practices

  • Start small. Set a daily cap you are comfortable losing, and give each ad 3 to 7 days before judging it.
  • Target communities, not broad interests. On Reddit, pick the subreddits your users already read.
  • Write ads like useful posts. Lead with the problem you solve; communities skip anything that reads like a pitch.
  • Judge by cost per signup, not clicks. It needs web analytics connected and links tagged here; a campaign renamed in the network stops matching its old links.
  • Recent days settle. Networks revise the last week as clicks are attributed; Araldo re-reads it daily.
  • Results stay 0 without a network's tracking pixel, which Araldo never asks for: count signups in your own analytics.
