Writing

  • # Heading, ## Smaller
  • **bold**, *italic*, [a link](https://…)
  • - item or 1. item for lists, > quote
  • --- alone for a divider
  • ![what it shows](media_…) alone for an image from the media library, or an https:// address
  • [Start a build](https://…){.button} alone for a button

Best practices

  • One main action. A single button gets more clicks than several links.
  • Subjects under 50 characters read whole on phones; preview text finishes the thought.
  • Describe every image; many readers see them blocked at first.
  • Send yourself a test and read it on a phone before scheduling.
  • Moving is safe until a copy is sent: Araldo moves it at each provider too.
